# Documentation conventions

Full rule content for `AGENTS.md`'s "## Docs" pointer and `md-format`'s pointer to it.
Read before writing or restructuring README.md or another top-level doc.

## Keep top-level docs short

Keep README.md and other top-level docs short.
Leave only the essential path inline - what the thing is, and a minimal quick-start.
Move secondary content into `<details><summary>...</summary>...</details>` blocks instead:

- Setup details
- Troubleshooting
- Advanced config
- Long output examples
